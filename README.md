# Digital Craft Studio

Build a completely new website for my company:

STARTUP SETUP

Do NOT base the design on a generic SaaS template.

Do NOT create a typical agency landing page.

Do NOT use the existing website structure as inspiration.

Start from a fresh visual concept.

I want this to feel like a premium digital product studio that actually designs and builds software for real businesses.

The website must look impressive enough that the website itself becomes part of our sales pitch.

==================================================

1. WHAT STARTUP SETUP IS

==================================================

Startup Setup is a digital product studio.

We design and build:

1. Custom business websites

2. Custom business software

3. Automation and AI-powered systems

Our core offerings are:

WEBSITES

CUSTOM SOFTWARE

Automation and AI can be positioned as capabilities that can be built into websites and software rather than making them feel like three unrelated services.

We work with businesses that need better digital infrastructure.

The positioning should feel:

premium

technical

practical

business-focused

modern

confident

NOT:

cheap agency

freelancer portfolio

generic marketing agency

AI wrapper

template shop

==================================================

2. OVERALL CREATIVE DIRECTION

==================================================

I want a visually stunning website with strong art direction.

The biggest problem with our previous design was that the entire page was almost white, with enormous empty spaces and small content floating inside them.

DO NOT repeat that.

The page needs:

- strong visual rhythm

- intentional contrast

- large visual moments

- rich product demonstrations

- controlled whitespace

- alternating visual surfaces

- strong typography

- subtle but meaningful motion

- editorial composition

- premium software-product aesthetic

Whitespace is good.

EMPTY SPACE is not.

Every large area of the screen should feel intentional.

The website should look excellent on a large desktop monitor, not merely acceptable on mobile.

4. COLOR SYSTEM

==================================================

Use a deliberate visual system instead of one white background across the entire page.

Primary light surface:

warm off-white / ivory

approximately:

#F5F3EE

Primary dark surface:

deep ink / almost black

approximately:

#101217

Primary brand accent:

electric blue

approximately:

#315BFF

You may tune these values slightly if needed.

Use the blue carefully.

Blue should communicate:

interaction

brand

important information

active states

CTAs

highlights

Do NOT cover the site in gradients.

Do NOT use purple/pink AI-style gradients.

Do NOT use random accent colors.

Teal/green may appear only inside software interfaces for states such as:

Live

Success

Connected

Completed

The overall site should have a sophisticated warm-light + deep-dark + electric-blue identity.

==================================================

5. TYPOGRAPHY

==================================================

Typography is extremely important.

Use a modern premium grotesk / sans-serif.

Prefer something with the character of:

Inter Tight

Geist

Söhne-style typography

or another excellent modern grotesk available in the environment.

Use a monospace font such as JetBrains Mono for:

URLs

technical metadata

project categories

small labels

numbers

browser chrome

Do NOT make the site dependent on serif italics.

Typography should feel:

confident

sharp

modern

editorial

technical

Headlines should be large but carefully controlled.

Avoid enormous headlines that consume 4–5 lines.

Avoid tiny body text.

==================================================

6. MOTION

==================================================

Motion is important.

I want the website to feel alive, but sophisticated.

Use:

- subtle reveal animations

- smooth section transitions

- hover states

- product UI movement

- scroll-linked transitions where appropriate

- gentle parallax

- cards that respond subtly to hover

- browser mockups that feel like real interfaces

A particularly important interaction:

In major product/service sections, product visual cards can transition or shift as the user scrolls.

Think of a stack of product cards or interfaces that reveal themselves sequentially.

The animation should feel intentional and premium.

DO NOT use:

- excessive bouncing

- cartoon animations

- spinning objects

- flashy gradients

- gimmicky cursor effects

- excessive blur

- unnecessary 3D

19. SPACING

==================================================

This is one of the most important requirements.

Do NOT use giant generic padding between every section.

Whitespace should create hierarchy, not emptiness.

Desktop should feel dense enough to look intentional.

Every viewport should contain meaningful visual information.

Use:

large product visuals

strong typography

section dividers

dark/light transitions

controlled content density

Avoid:

huge blank fields

tiny cards floating in giant containers

small text surrounded by empty space

==================================================

1920px

At tablet/mobile:

preserve hierarchy

keep product demos prominent

avoid tiny unreadable UI

reduce motion where necessary
